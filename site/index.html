01 / Current flow

Failures return to the full processing path

Processing acknowledges on receipt. Every failed delivery returns to the event bus and repeats processing, including enrichment. Slow enrichment and delivery retries can therefore compound the backlog.

Open question: does acknowledgment on receipt leave any durable owner of unfinished work? Confirm the actual recovery contract before concluding that a crash loses events.

Conceptual design exercise. Proposals are not deployed or measured results. No infrastructure provider is assumed.
